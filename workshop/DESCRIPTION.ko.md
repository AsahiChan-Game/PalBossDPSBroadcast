[h1]내 DPS 보지 마[/h1]
[b]Palworld 1.0 싱글 플레이용 가벼운 보스 피해량 측정 모드입니다.[/b]

보스를 공격하면 자동으로 집계를 시작합니다. 보스를 처치하거나 포획하거나 전투가 시간 초과되면 게임 채팅에 결과가 표시됩니다.

[h2]주요 기능[/h2]
[list]
[*]팀 피해, 전투 시간, DPS, 플레이어 순위와 피해 비율
[*]플레이어 캐릭터와 각 팰의 피해를 분리 집계
[*]사용자가 지정한 팰 별명을 우선 표시
[*]여러 부위로 구성된 보스를 하나의 전투로 통합
[*]Palworld가 지원하는 17개 언어 자동 적용
[*]선택형 실시간 보고, 상세 수상, 팰별 내역
[/list]

[h2]설치[/h2]
[olist]
[*]이 모드를 구독합니다.
[*][url=https://steamcommunity.com/workshop/filedetails/?id=3625223587]UE4SS Experimental (Palworld)[/url]을 구독하고 활성화합니다.
[*]Palworld 모드 관리자에서 두 모드를 모두 활성화합니다.
[*]싱글 플레이 월드에 들어가 보스를 공격합니다.
[/olist]

[h2]팰별 피해량[/h2]
v1.2.0부터 플레이어 캐릭터와 각 팰의 피해, 비율, DPS가 기본으로 표시됩니다. [code]config.EnablePalDamageBreakdown = true[/code]에서 설정하며, 짧은 결과를 원하면 [code]false[/code]로 바꾸세요. 보스 전투장은 지원하지만 PvP 아레나는 지원하지 않습니다.

[h2]지원 범위[/h2]
[list]
[*][b]지원:[/b] 싱글 플레이 월드
[*][b]실험적 지원:[/b] 호스트 모드, 호스트에게만 표시
[*][b]미지원:[/b] 원격 클라이언트에서 서버 전체 팀 피해 집계
[/list]
