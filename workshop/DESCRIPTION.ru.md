[h1]Не проверяй мой DPS[/h1]
[b]Лёгкий счётчик урона по боссам для одиночных миров Palworld 1.0.[/b]

Ударьте босса, чтобы автоматически начать подсчёт. Результат появится в игровом чате после победы, поимки или завершения боя по тайм-ауту.

[h2]Возможности[/h2]
[list]
[*]Урон команды, время боя, DPS, рейтинг и доля урона
[*]Отдельный учёт урона персонажа и каждого Пала
[*]Приоритет пользовательского имени Пала
[*]Объединение многочастных боссов в один бой
[*]Автоматический выбор одного из 17 языков Palworld
[*]Дополнительные отчёты в реальном времени, награды и детализация по Палам
[/list]

[h2]Установка[/h2]
[olist]
[*]Подпишитесь на этот мод.
[*]Подпишитесь и включите [url=https://steamcommunity.com/workshop/filedetails/?id=3625223587]UE4SS Experimental (Palworld)[/url].
[*]Включите оба мода в менеджере модов Palworld.
[*]Войдите в одиночный мир и атакуйте босса.
[/olist]

[h2]Поддержка[/h2]
[list]
[*][b]Поддерживается:[/b] одиночная игра
[*][b]Экспериментально:[/b] режим хоста, показ только хосту
[*][b]Не поддерживается:[/b] серверный урон команды с удалённого клиента
[/list]

Для выделенных серверов используйте серверную версию на [url=https://github.com/AsahiChan-Game/PalBossDPSBroadcast]GitHub[/url].

[i]Неофициальный мод сообщества, не связанный с Pocketpair, Steam или UE4SS. Исправления перевода приветствуются.[/i]
